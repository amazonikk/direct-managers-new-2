# Direct Managers Dashboard v3

Виправлена версія.

## Логіка
- Місяць відкривається як загальний місячний звіт.
- Усередині місяця показуються Тиждень 1, 2, 3, 4, 5.
- Натискання на тиждень відкриває деталі тижня.
- Усередині тижня видно Пн–Нд і результати кожного дня.
- Доступні фільтри менеджера, платформи та конкретних акаунтів.
- По акаунтах показується ріст/стабільність/просідання.
- Числові поля оброблених коментарів підтримуються окремо.

## Важливе виправлення Code.gs
Порожні майбутні рядки з формулами, що повертають 0, більше не вважаються активністю. Заголовки знову скануються в перших 8 рядках, як у старому робочому Apps Script.

## Встановлення
1. Замінити код нового Google Apps Script на `Code.gs`.
2. Запустити `testBackend()` вручну.
3. Deploy → Manage deployments → Edit → New version → Deploy.
4. На GitHub замінити `index.html`, `app.js`, `styles.css`.
5. `app.js` уже містить URL нового Apps Script Web App.
