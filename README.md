# Direct Managers Dashboard v2

Це готова заміна фронтенду + оновлений Google Apps Script API.

## Що додано

- Перегляд: **День / Тиждень / Місяць**.
- Попередній / наступний період.
- Календарні тижні **понеділок–неділя**.
- Фільтр менеджера.
- Фільтр платформи: TikTok / Instagram / Facebook / Telegram / YouTube / Email / Інше.
- Зручний multi-select акаунтів з пошуком.
- KPI: чати, отримані номери, конверсія, оброблені коментарі.
- Порівняння з попереднім аналогічним періодом.
- Статус кожного акаунта: **Росте / Стабільно / Просідає**.
- Таблиця та окремі мобільні картки по кожному акаунту.
- Адаптивні графіки для телефону.
- RTO / YouTube аркуші з числовими коментарями більше не ігноруються.

## Важливо про коментарі

Звичайна колонка `КОМЕНТАРІ` у direct-таблицях є текстовою приміткою і не рахується.

API рахує тільки числові поля:
- `ОБРОБЛЕНО КОМЕНТАРІВ`
- `Усього коментарів`
- `Всього коментарів`
- `Кількість коментарів`

## 1. Оновити Apps Script

1. Відкрий поточний Google Apps Script, який використовується дашбордом.
2. Замінити код на файл `Code.gs`.
3. Запустити `testBackend()` вручну один раз.
4. Перевірити в Logger, що повертаються managers/accounts/records.
5. `Deploy` → `Manage deployments`.
6. Відкрити поточний Web App deployment → `Edit`.
7. Обрати **New version** → `Deploy`.

Якщо оновлюєш існуючий deployment, URL Web App лишиться той самий і `app.js` змінювати не треба.

Якщо створиш НОВИЙ Web App deployment з іншим URL — заміни `APPS_SCRIPT_URL` на початку `app.js`.

## 2. Оновити GitHub Pages

У корені репозиторію замінити:

- `index.html`
- `styles.css`
- `app.js`

Папку `data/` можна залишити як є — вона використовується лише як резервна копія, якщо Apps Script тимчасово недоступний.

## 3. Оновлення кешу

У `index.html` уже стоять:
- `styles.css?v=2`
- `app.js?v=2`

Якщо GitHub Pages/браузер покаже стару версію, зроби hard refresh.

## Як рахується тренд

- **День:** обрана дата vs попередня календарна дата.
- **Тиждень:** понеділок–неділя vs попередній понеділок–неділя.
- **Місяць:** обраний календарний місяць vs попередній місяць.

Статус лідів:
- > +5% → `Росте`
- від -5% до +5% → `Стабільно`
- < -5% → `Просідає`
- якщо попередній період = 0, а поточний > 0 → ріст з нуля.

## Файли

- `Code.gs` — Apps Script API v2.
- `index.html` — нова структура дашборду.
- `styles.css` — desktop + mobile UI.
- `app.js` — фільтри, періоди, тренди, графіки та аналітика.
- `Code-original.js` — копія коду, який був наданий до змін.
